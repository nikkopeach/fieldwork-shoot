# fieldwork. — family shoot companion

A mobile-first offline-capable standalone shoot reference sheet for November 22, 2026. Camera, run-of-show, frames and crew checklist. No account, telemetry or data submission. Checkmarks are stored only in the visitor's current browser/device.

## GitHub Pages deployment (public)

Create a NEW public GitHub repository (e.g. `fieldwork-shoot`), then upload the files from this ZIP to the repository root (do not upload the ZIP itself). In repository Settings → Pages, choose **Deploy from a branch**, `main`, `/ (root)`, then Save. Once Pages builds, the URL is generally `https://YOUR-USERNAME.github.io/fieldwork-shoot/` (verify the actual URL from GitHub; do not assume live until Pages confirms).

**Privacy:** GitHub Pages from a public repository is accessible to anyone who knows or discovers the URL, including first names on this family run sheet. If that is unacceptable, do not enable Pages; use a private hosting service instead.

On iPhone: open the deployed site in Safari → Share → Add to Home Screen. The actual PNG `apple-touch-icon.png` is included so the Home Screen icon is not a generic screenshot. Open the installed app once online, then check offline behavior before depending on it.

## What works
- Eight timed run-of-show blocks and inline timer
- Six essential and optional frame checkmarks
- Nikon Z6 II settings for full 11, smaller groups, toddler, quiet portraits and 16–35mm environmental frames
- Natural Light Auto / RAW-based style notes; reflector cues; weather-light choices
- Crew roles and packable gear only, optional gear separately
- Local on-device state; no sync or remote logging
